CAN AX MVP 시작 순서
====================

1) RUN_FIRST.bat 실행
2) 끝나면 RUN_APP.bat 실행
3) 웹 화면에서 Bundled demo incident 분석 확인
4) LEARN_THIS_FIRST.md 읽기
5) DATASET_GUIDE.md를 보고 HCRL 실제 데이터 다운로드
6) data/raw 폴더에 실제 파일 넣기
7) TRAIN_REAL_DATA.bat 실행
8) RUN_APP.bat 재실행
9) EXPERIMENTS.md의 실험 3개 직접 수행
10) INTERVIEW_QA.md로 면접 준비

중요:
- 기본 ZIP의 데이터/모델은 합성 DEMO입니다.
- 데모 성능을 이력서/자소서에 쓰지 마세요.
- 실제 HCRL 재학습 결과만 사용하세요.
